# Ilustrasi Maskot Eksplorasi Beranda

PNG di folder ini adalah sumber ilustrasi untuk tiga kartu Eksplorasi. Aset runtime WebP berada di `assets/images/mascot/`.

Semua ilustrasi dibuat sebagai cutout transparan menggunakan `mascot.png` sebagai acuan rupa dan warna, serta `mascot-turnaround.webp` sebagai acuan anatomi dan proporsi.

| PNG sumber | Aset runtime | Pose |
| --- | --- | --- |
| `artikel.png` | `home-artikel.webp` | RuNa duduk membaca buku terbuka tanpa tulisan. |
| `cerita.png` | `home-cerita.webp` | RuNa memeluk jurnal kecil sambil mengajak berbagi cerita. |
| `forum.png` | `home-forum.webp` | RuNa mencondongkan badan dalam pose mendengarkan dan menyambut percakapan. |

Pertahankan pose dan identitas kanonis saat membuat varian. Hindari teks, logo tambahan, watermark, karakter lain, latar adegan, dan pemotongan bagian tubuh. Jika aset diperbarui, optimalkan kembali ke WebP dengan transparansi alpha dan jangan menimpa master atau turnaround.
